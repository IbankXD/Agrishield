AgriShield AI — สรุปเนื้อหานำเสนอ Week 13 (Model Gate)

ระบบวินิจฉัยโรคพืชและสนับสนุนการตัดสินใจเพื่อลดการใช้สารเคมี (บูรณาการ CSI410, CSI411, CSI413, CSI414)
กลุ่มที่ 32 | สมาชิก: นายศิวัฒน์ แก้วหนองสังข์ & นายธนวัฒน์ ณรงค์วงค์วัฒนา

1. การทบทวนขอบเขตและการปรับปรุงข้อมูล (Data Scope & Recap)

  • ชุดข้อมูลรวมสมบูรณ์: พืชเศรษฐกิจ 4 ชนิด ได้แก่ มะเขือเทศ (Tomato), ข้าวโพด (Corn), มันฝรั่ง (Potato), และข้าว (Rice) รวม 23 คลาส (29,493 ภาพ)
  • การแก้ไขตามคำแนะนำของอาจารย์จากรอบ Data Gate:
    • ดึงภาพถ่ายแปลงจริงของมันฝรั่งจากภายนอก (muhammadardiputra) มาเสริม เพื่อแก้ปัญหาข้อมูลสำเร็จรูปเกินไป
    • แบ่งสัดส่วนข้อมูลใหม่เป็น 70% Train (20,636 ภาพ) : 30% Test (8,857 ภาพ) แบบ Stratified Split
    • ปรับ Data Augmentation เป็น Geometric Only (ตัดการเปลี่ยนสีและภาพขาวดำออก เพื่อรักษารงควัตถุของรอยโรคพืช)

2. โมเดลที่นำมาเปรียบเทียบ (Baseline vs Candidate Models)

จำแนกการศึกษาเปรียบเทียบออกเป็น 3 สถาปัตยกรรม:

  • Baseline Model: Simple Custom CNN (3 Convolutional Layers) สร้างและเทรนจากศูนย์ (Train from scratch) เพื่อใช้เป็นเกณฑ์มาตรฐานขั้นต่ำ
  • Candidate 1 (โมเดลตัวเลือกหลัก): MobileNetV3 Large (Pre-trained on ImageNet) สถาปัตยกรรม Depthwise Separable Convolution เน้นขนาดเล็กและประมวลผลเร็ว
  • Candidate 2 (โมเดลเปรียบเทียบ): ResNet50 สถาปัตยกรรมลึก 50 ชั้นพร้อม Residual Connection สำหรับเปรียบเทียบเชิงสถาปัตยกรรมขนาดใหญ่

3. ตัวชี้วัดและการแก้ปัญหา Class Imbalance (Evaluation Strategy)

  • การแก้ปัญหาในขั้นตอนการเทรน: ใช้เทคนิค Cost-Sensitive Learning ผ่าน Balanced Class Weights คำนวณค่าน้ำหนักผกผันกับจำนวนภาพจริง ส่งให้ CrossEntropyLoss บังคับให้โมเดลลงโทษคลาสที่มีภาพน้อย (เช่น มันฝรั่ง) หนักขึ้น
  • ตัวชี้วัดหลัก: ชู Macro F1-Score (และ Recall) เป็นเกณฑ์ตัดสินหลักแทน Accuracy เพื่อให้ทุกคลาสโรคได้รับความสำคัญเท่าเทียมกัน

4. ผลการทดลองเปรียบเทียบ (Benchmark Results)

ผลการประเมินบนชุดทดสอบจริง Unseen Test Set (30% — 8,857 ภาพ):

โมเดล (Model) แนวทาง (Approach) Test Accuracy Macro F1-Score ขนาดไฟล์ Inference Time ผลการตัดสิน
Simple Custom CNN Train from Scratch (3 Layers) 85.20% 0.7930 ~13.2 MB ~12 ms ❌ ประสิทธิภาพไม่เพียงพอ
ResNet50 Transfer Learning (50 Layers) 99.10% 0.9895 ~98.0 MB ~48 ms ⚠️ ไฟล์ใหญ่เกินไปสำหรับ Edge
MobileNetV3 Large ⭐ Transfer Learning + Class Weights 99.49% 0.9919 ~16.4 MB ~18 ms ⭐ SELECTED (ชนะเลิศ)
พลวัตการเรียนรู้ (Training Dynamics): โมเดล MobileNetV3 ลู่เข้าสู่อิ่มตัวอย่างมั่นคงตั้งแต่ Epoch ที่ 7 โดยได้ Test Accuracy 99.49% และ Test Loss ต่ำเพียง 0.0228 โดยไม่มีปัญหา Overfitting

5. การวิเคราะห์ข้อผิดพลาด (Error Analysis จาก Confusion Matrix)

  • กลุ่มโรคข้าวและข้าวโพด: ทำนายถูกต้องสมบูรณ์แบบ 100% ทุกภาพ
  • จุดที่โมเดลเกิดความสับสนเล็กน้อย (< 0.5%):
    • Tomato Early Blight สับสนกับ Tomato Bacterial Spot (3 ภาพ) เนื่องจากในระยะเริ่มต้นมีแผลเป็นจุดสีน้ำตาลขอบเปื่อยคล้ายคลึงกัน
    • Potato Early Blight สับสนกับ Potato Late Blight (2 ภาพ) ในระยะที่ใบเริ่มไหม้เกรียมเป็นบริเวณกว้าง
  • แนวทางแก้ไขในการใช้งานจริง: หากโมเดลมีค่าความมั่นใจ (Confidence Score) ต่ำกว่า 85% ระบบจะแสดงผลคำทำนายแบบ Top-2 ให้เกษตรกรตรวจสอบลักษณะวงแหวนของแผลเพิ่มเติม

6. เหตุผลทางวิศวกรรมในการเลือกโมเดล (Model Selection Rationale)

กลุ่ม 32 ตัดสินใจเลือก MobileNetV3 Large เป็นโมเดลหลักของโครงงาน ด้วยเหตุผล 3 ประการ:

  1. ความแม่นยำสูงสุด (High Performance): ได้รับค่า Macro F1-Score สูงสุดถึง 0.9919 (99.19%) เหนือกว่า Baseline CNN ชัดเจน
  2. ขนาดไฟล์กะทัดรัด (Ultra-Lightweight): ขนาดไฟล์เพียง 16.4 MB (เล็กกว่า ResNet50 ถึง 6 เท่า) สะดวกต่อการโหลดขึ้น Cloud และรันบน Web Browser
  3. ความเร็วในการประมวลผล (Low Latency): ใช้เวลาประมวลผลเพียง 18 มิลลิวินาทีต่อภาพ เหมาะอย่างยิ่งกับการนำไปทำเป็น Mobile Web Application ให้เกษตรกรถ่ายภาพและรู้ผลทันทีในแปลงจริง

7. แผนงานระยะถัดไป (Next Steps)

  • การพัฒนาแอปพลิเคชัน: นำโมเดล MobileNetV3 ไปเชื่อมต่อเข้ากับระบบ Web Application (FastAPI/React)
  • ระบบสนับสนุนการตัดสินใจ: เชื่อมต่อผลวินิจฉัยเข้ากับ ฐานข้อมูลคำแนะนำชีวภัณฑ์ (Biocontrol Recommendation DB) เพื่อแนะนำแนวทางการรักษาตามธรรมชาติแทนการซื้อสารเคมี (สอดคล้องกับเป้าหมาย SDG 12)
